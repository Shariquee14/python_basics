git init                             # 1. start tracking (once per project)
git add .                            # 2. stage all changed files
git commit -m "Day 1: Python intro"  # 3. save a version with a message
git remote add origin <repo-URL>     #    link to GitHub (once per project)
git branch -M main
git push -u origin main              # 4. upload to GitHub
# Next time only: git add .  ->  git commit -m "..."  ->  git push


[MEMORY TRICK] add = put your files in the box. commit = seal the box and write a label on it. 
push = send the box to GitHub. Three steps, every time.
